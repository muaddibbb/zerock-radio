## How it works
1. Board built from SHOW_SCHEDULE + queue overrides + Erev Albumim/Al Haroker bookings (`_build_wp_schedule_slots` ~5005), rendered as 4 day-group grids (`_build_wp_schedule_html` ~5320).
2. `_sync_wp_board` (5534): background thread under a lock; 5 independent POST/PUTs with WP_USER/WP_APP_PASS: mu-plugin route `zerock/v1/schedule` (board HTML), options `zerock_board_html` and `zerock_now_playing_json`, PUT page 254, option `ihaf_insert_footer` (CSS + board HTML + `zerock-fix` script).
3. Footer script fetches `/wp-json/zr/v1/np`, patches `.hp-live-now`/`.hp-next-show` text via textContent, swaps image from `_WP_SHOW_ART_URLS` (embedded with json.dumps).
4. Publishing: uploader on 114 first; `_create_wp_post_direct` (1653) fallback; `_verify_and_fix_wp_post` (1787) patches status/featured/shows/ACF/title/slug; `_check_wp_posts` (2829) 30-min safety net; `_publish_wp_post` flips future posts to publish.
5. Names/IDs/slugs from hard-coded maps (87-238, 4897): _WP_SHOW_SLUGS, _WP_SLUG_BY_HOST, _wp_episode_slug, _WP_FEATURED_IMAGES, _WP_SHOW_IDS, _WP_BROADCASTER_IDS, _WP_SLUGS.
6. after_request hooks (311, 335) inject logo + Kupernet footer into every HTML response.
7. Templates use Jinja autoescape and tojson (show_form.html:551). PHP snippets render the homepage widget.
8. Live board matches the code: injected art map identical to _WP_SHOW_ART_URLS; exactly one `zerock-fix` script; 4 groups, 0 overlapping cells.
